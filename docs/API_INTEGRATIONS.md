# Planlanan adaptörler (henüz canlı değil)

Shopify: Admin GraphQL API + signed webhook; HMAC, retries, idempotent event ingestion, fulfillment/tracking API.
Amazon: Selling Partner API, Orders API, restricted personal-data access, seller FBM vs FBA distinctions.
Idealo: desteklenen Checkout Order API; yönlendirme siparişleri mağaza kaynağından al ve çift sayma.
ShipStation: shipping API v2, label creation, tracking reconciliation. Paid label duplication prevention.
Shippo/Sendcloud/DHL/DPD: yetkilendirme ve rate limit araştırılarak takılabilir adaptörler.
API anahtarları ve canlı ortam onayı olmadan tümü plan aşamasındadır.
